# Getting started

Enter this in the terminal


### Create a Venv

=== "Windows"

    ```bash
    python -m venv venv
    venv\Scripts\activate
    ```

=== "Linux"

    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```
### Install Requirements

```bash
pip install -r requirements.txt
```

### start it up
mkdocs serve
